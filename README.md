1. Інтеграція з API. Має інтегрувати кошти для різних валют. Товар у $ коли купляєш перетворює у гривні на основі актуальних даних, а потім списує це в гривнях із рахунку.

2. Підтримка мультивалютності в реальному часі: Інтегруйте API курсів валют (наприклад, ExchangeRate-API) для автоматичного перерахунку балансу та аналізу інвестицій у різних валютах. Тобто клієнт може вибрати у якій валюті в нього будуть кошти.

3.Генератор звітів у PDF/Excel: Реалізуйте експорт детальних фінансових звітів з графіками (використовуючи бібліотеки на кшталт QuestPDF або EPPlus).
- кількість витрати за конкретний період часу
- кількість витрат за конкретний тип
- стагнації суми витрат
- графік витрат потижнево, та помісячно

4. Система сповіщень про ліміти: Налаштуйте логіку попереджень, коли витрати в категорії наближаються до встановленого ліміту в день. Нагадування смс на пошту про ліміт.

5. Модуль управління боргами: Створіть окремий трекер для кредитів та позик з розрахунком графіку погашення та відсотків.
   Якщо ти зичиш кошти у банку, то кожен день відсотки та нагадування про них на пошту разом із сумою.

6. Можливість вести спільний бюджет з іншим користувачем (наприклад, для сім'ї), де кожен бачить витрати іншого в реальному часі.
